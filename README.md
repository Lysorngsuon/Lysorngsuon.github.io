# Lysorngsuon.github.io

Official personal academic and industry website repository for **Suon Lysorng**.

🌐 **Live Website:** [https://lysorngsuon.github.io/](https://lysorngsuon.github.io/)

---

### Features & Architecture
- **Academic & Industry Layout:** Inspired by Minimal Mistakes / AcademicPages (similar to `luboshanus.github.io`).
- **Two-Column Responsive Design:** Sticky left sidebar featuring profile details, affiliations, contact points, and CV download.
- **Academic Publications Section:** Complete citations with publisher DOI links and interactive BibTeX copy drawer.
- **Teaching & Masterclasses:** Detailed overview of lecture engagements at the Institute of Finance & Accounting (IFA) and EuroCham Cambodia.
- **Projects & Portfolios:** Interactive category filtering for Financial Modeling, Power BI Dashboards, and Power Platform / SAP Automation.
- **Light & Dark Theme:** Built-in theme switcher with automatic preference detection.
- **Zero Build Dependencies:** Pure HTML5, modern CSS3 variables, and vanilla JavaScript—100% reliable and fast loading on GitHub Pages.
